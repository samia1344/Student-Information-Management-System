# لوحة نتائج الطلاب — Student Results Dashboard

**إعداد:** سامية وحيد شعبان  
**الرقم الجامعي:** 2302572

تكليف عملي: دمج البرمجة كائنية التوجه (Classes) مع `map` و`filter` و`reduce`.

## ما يفعله المشروع
- كلاس `Student` يحسب المتوسط (`reduce`) والتقدير (`if/else`) والنتيجة (`&&`).
- لجنة رأفة: `filter` ثم `map` ثم `reduce` مع درع حماية من القسمة على صفر.
- لوحة ويب: كشف درجات، رسم دائري للتقديرات، مقارنة قبل/بعد الرأفة، إضافة طالب، وConsole مباشر.

## التشغيل
```bash
node script.js
```
أو افتح `index.html` في المتصفح ثم F12.

## الملفات
`script.js` المنطق المطلوب · `index.html` + `styles.css` + `dashboard.js` الواجهة
